# FLY — BLACK WING / 黑翼

废墟之城 · 猎魔行动  
Helicopter combat game (Three.js)

## Play online

**GitHub Pages 地址（启用后）：**  
https://jungle-eyes.github.io/FLY/

### 如何启用 GitHub Pages
1. 打开仓库：https://github.com/Jungle-Eyes/FLY
2. 点击 **Settings** → 左侧 **Pages**
3. Source 选择 **Deploy from a branch**
4. Branch 选 **main**，文件夹选 **/ (root)**
5. 点击 Save
6. 等待 1～2 分钟后访问上面的链接即可游玩

## 操作说明
- 手机：左下摇杆移动，右下射击，右侧滑杆调高度，拖动空白处转动视角
- 电脑：WASD / 方向键移动，Q/E 升降，空格射击，鼠标拖动视角
